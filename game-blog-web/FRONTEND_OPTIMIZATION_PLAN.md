# Frontend Optimization Plan

## 已完成（P0 + P1）

### P0 可用性与移动端
- 管理端导航重构：桌面侧栏 + 移动端抽屉菜单，支持点击菜单自动收起。
- 博客端导航重构：桌面横向菜单 + 移动端抽屉菜单。
- 导航路由联动收口：路由切换时，移动端菜单自动关闭，避免遮挡页面。
- 关键页面移动端适配：`ArticleList` 新增移动卡片布局，`Publish`/`Login`/`AiVideo` 优化小屏布局。

### P1 主题与性能
- 新增全局主题变量文件：`src/styles/theme.css`。
- 统一主色、文字色、边框、圆角、阴影等设计 token，核心页面改造为变量驱动。
- 新增暗色变量（`prefers-color-scheme: dark`）作为后续深色模式基础。
- Markdown 编辑器从全局注册改为页面按需加载（动态 import），减少非编辑页首屏负担。
- ECharts 与 Markdown 均已切分独立 chunk，降低主包压力。

## 待办（P2，后续执行）

### 体验一致性
- 统一空状态、错误状态、骨架屏组件，并在文章/记账/视频页复用。
- 统一操作反馈文案与时长（发布、删除、保存、网络异常）。
- 统一加载体验（按钮 loading、列表 loading、页面 loading 的语义边界）。

### 工程化与质量保障
- 增加基础 UI 规范文档（颜色、间距、断点、排版、按钮尺寸）。
- 引入或加强 lint 规则，约束样式硬编码与组件结构一致性。
- 为核心路径补充 E2E：登录、导航、文章管理、记账增删、移动端菜单收起。

### 性能深化
- 继续细分 `element-plus` 与 `markdown` chunk，降低单 chunk 峰值。
- 图片/视频资源增加懒加载与占位策略，优化弱网体验。
