# MVP 产品需求文档：小区对比助手

## 1. 产品定位
一款面向购房者的工具类小程序，通过结构化的数据对比（价格、物业、居住环境、教育配套等），量化不同小区的优劣，并联动房贷计算器提供财务参考。

## 2. 核心功能模块

### 2.1 小区搜索与管理
- [搜索]：支持关键词模糊搜索小区名称。
- [选择]：点击搜索结果加入“对比栏”，MVP阶段支持选择 2-3 个小区。
- [管理]：在对比页可以随时删除某个小区，并重新添加。

### 2.2 数据对比矩阵 (Core)
对比维度分为四个核心层级，由后端 API 统一返回：

| 维度分类 | 包含字段 | 备注 |
| :--- | :--- | :--- |
| **交易动态** | 挂牌均价、近一年涨跌幅、近期带看、在售房源 | 体现市场热度和保值性 |
| **基础信息** | 建成年代、开发商、物业公司、建筑类型 | 体现房产寿命和品牌背书 |
| **居住品质** | 容积率、绿化率、车位配比、梯户比、人车分流 | 体现居住舒适度 |
| **费用成本** | 物业费、停车费、水电类型(民/商) | 体现日常持有成本 |
| **外部资源** | 对应小学、对应中学、最近地铁距离 | 体现溢价能力 |

### 2.3 房贷联动计算
- [自动取值]：对比页直接抓取小区“挂牌均价”。
- [默认计算]：预设 90㎡ 为标准面积，调用已有后端房贷逻辑。
- [结果显示]：在对比列表底部，显示每个小区的“参考首付”与“参考月供”。
- [深度跳转]：点击计算结果，携带该小区单价参数跳转至现有的“房贷计算器”页面进行详细调整。

### 2.4 对比海报生成
- [功能描述]：将当前对比的 2-3 个小区数据渲染成一张长图海报。
- [海报内容]：小区核心数据对比表 + 房贷参考值 + 小程序码。
- [技术路径]：建议后端 Canvas 渲染或小程序端 wxml-to-canvas 组件。

---

## 3. 技术实现方案

### 3.1 数据来源方案
- [路径 A：爬虫抓取]：针对主流房产平台（如贝壳、链家）的公开页面进行定期抓取，获取小区基础属性和动态价格。
- [路径 B：开放数据集]：寻找 GitHub 或地产研究机构公开的城市小区 CSV/JSON 数据库作为冷启动底座。
- [路径 C：手动/众包]：MVP 阶段仅维护 100-200 个热门小区，并在页面提供“申请添加小区”入口。

### 3.2 前端交互逻辑
- [吸顶效果]：小区名称和头图在页面向上滑动时需“吸顶”固定，方便用户核对下方数据所属小区。
- [差异标记]：前端根据逻辑对优选项进行视觉高亮（如：容积率越小，字体显示为绿色或加粗）。
- [自适应]：当对比 2 个小区时，每列占比 45%；当对比 3 个小区时，自动缩小字号或允许横向滑动。

### 3.3 后端接口设计
- [GET /api/community/search]：根据关键词返回小区列表。
- [POST /api/community/compare]：传入 community_id 数组，返回聚合后的详细对比 JSON 报文。
- [GET /api/poster/generate]：接收对比参数，返回生成后的海报图片 URL。

## 4. 后续版本扩展规划 (Future Scope)
1. [更多小区对比]：支持 5 个及以上小区对比，采用“首列固定，右侧横滑”的交互。
2. [用户评价体系]：引入真实住户对小区噪音、物业服务、周边环境的打分。
3. [价格趋势图]：引入 Echarts，展示不同小区近三年的价格走势对比。
4. [地图找房对比]：在地图上选定一个区域，直接拉取该区域内性价比最高的 3 个小区进行对比。

---

## 5. MVP 成功指标
1. [使用深度]：用户单次访问对比 2 个及以上小区的比例。
2. [传播价值]：对比海报的生成量与通过海报二维码扫码进来的新用户数。
3. [计算器联动]：从对比页跳转至房贷计算器页面的点击率。
