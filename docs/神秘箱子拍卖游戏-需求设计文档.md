# 神秘箱子拍卖游戏 - 需求设计文档
## 1. 游戏概述
**游戏名称**：神秘箱子拍卖游戏（暂定）  
**游戏类型**：多人在线竞拍博弈游戏  
**核心玩法**：玩家通过信息博弈和竞价策略，拍卖神秘箱子中的物品，通过信息获取和风险评估获取收益。
---
## 2. 核心游戏机制
### 2.1 房间机制
- 房间容量：2-4人
- 房间类型：公开房间（随机匹配）/ 私人房间（邀请加入）
- 房间状态：等待中 → 游戏中 → 结算中 → 已结束
- 出价超时：1分钟（V1固定，后续支持房间配置）
### 2.2 箱子机制
#### 2.2.1 箱子规格
- 尺寸：横排20格 × 竖排100-150格（随机生成）
- 物品布局：不完全填满，保持一定空隙
- 物品尺寸：1×1到4×4矩形格子
- 填充密度：随机50%~90%
#### 2.2.2 物品品质与价值体系
| 品质 | 颜色 | 价值范围 | 出现概率 |
|------|------|----------|----------|
| 普通 | 白色 | 5-500 | 50% |
| 优秀 | 绿色 | 200-800 | 25% |
| 稀有 | 蓝色 | 500-2000 | 15% |
| 史诗 | 橙色 | 1000-5000 | 8% |
| 传说 | 红色 | 3000-10000 | 2% |
**价值计算规则**：
- 每个具体物品在对应品质的价值范围内随机生成固定价值
**物品库规模比例（按品质总量占比）**：
- 白15% / 绿25% / 蓝35% / 橙25% / 红10%
**单个物品出现概率**：
- 先按品质权重抽取，再在该品质物品池内按权重抽取  
- 默认同品质内均匀分布，可后续做轻度加权
#### 2.2.3 信息揭示机制
- 初始暴露：随机显示3-6个物品的品质（仅品质，不显示具体物品信息和价值）
- 起拍价计算：
  - 起拍价 = Σ(已暴露品质的平台平均价)
  - 示例：2个白色 + 1个橙色
  - 起拍价 = 白色均价 × 2 + 橙色均价
- 平台均价：固定静态表（V1）
#### 2.2.4 物品填充与排序策略
- **填充密度**：随机50%~90%
- **空间占用策略**：
  - 优先使用大件物品，后续用小件补空
  - 尽量减少碎片空隙
- **上半箱子优先**：
  - 若填充密度为50%，尽量把物品集中在箱子上半部分
  - 算法目标：在保证随机性的前提下，最大化上部区域覆盖率
- **放置方向**：允许旋转90°（可配置开关）

## 3. 拍卖机制
### 3.1 拍卖流程
最多5轮竞价，每轮规则：
| 轮次 | 成交条件 |
|------|----------|
| 第1轮 | 最高价 ≥ 第二高价 × 200%（即高100%） |
| 第2轮 | 最高价 ≥ 第二高价 × 180%（即高80%） |
| 第3轮 | 最高价 ≥ 第二高价 × 150%（即高50%） |
| 第4轮 | 最高价 ≥ 第二高价 × 120%（即高20%） |
| 第5轮 | 最高价者直接成交 |
### 3.2 出价规则
- 超时处理：超时未出价视为放弃，不参与后续轮次
- 最低加价：每次加价不低于起拍价的5%
- 资金冻结：出价时冻结对应金额，放弃或被超价时解冻
- 技能卡限制：一次拍卖中每轮可使用1张技能卡，同一技能卡在该拍卖中仅可使用一次
---
## 4. 角色与技能系统
### 4.1 角色与基础技能（自带）
- **鉴赏家**：开局随机显示2-3个物品的品质  
- **估价师**：开局显示1个物品的价值范围（±20%）  
- **墓志学者**：开局显示箱子里某一品质的数量  
- **碎片修复师**：开局显示1个物品的尺寸（占格）  
- **纹饰辨识者**：开局显示1个物品的“器型类别”（不显示具体物品）  
- **占位规划师**：开局显示箱子内物品填充密度（±10%）  
- **运筹师**：若未出价直接放弃，本轮自动返还1次技能卡（仅限一次）
### 4.2 技能卡（商城购买）
- **透视眼**：查看任意1个未揭示物品的具体信息  
- **价值探测器**：显示箱子总价值的大致范围（±30%）  
- **品质雷达**：显示箱子中各品质物品的数量  
- **价格锚点**：显示起拍价与实际价值的偏差（偏高/偏低）  
- **埋藏密度仪**：显示箱子填充密度（±5%）  
- **图格透写**：显示箱子上半区的占格分布热区（不显示物品细节）  
- **偏移镜**：随机显示1个物品的尺寸和品质  
**技能卡规则**：
- 每轮拍卖可使用1张技能卡  
- 技能卡使用后消耗  
- 技能卡可在商城购买或活动获取  
---
## 5. 经济系统
### 5.1 初始资金
- 新用户注册赠送10,000金币
### 5.2 收益来源
1. **拍卖成功**：获得箱子内所有物品  
   - 可选择保留物品或一键售卖  
   - 一键售卖规则：默认勾选除红色品质外的所有物品  
2. **围观奖励**：当拍卖成功者亏损时  
   - 亏损金额 × 10% 平均分配给其他未放弃的参与玩家  
   - 仅限本轮有出价且未放弃的玩家  
### 5.3 损失风险
- 拍卖成功者：购买价格 - 箱子实际价值 = 净盈亏  
- 拍卖失败者：无直接损失（可能损失技能卡）

## 7. 游戏流程
### 7.1 房间准备阶段
1. 玩家创建/加入房间
2. 等待2-4人满员
3. 系统生成箱子（随机尺寸、随机物品、填充密度）
4. 系统揭示初始信息（3-6个物品品质）
5. 计算起拍价
6. 玩家选择是否使用技能卡（可选）
### 7.2 拍卖阶段
第1轮：
  - 所有玩家出价（或超时放弃）
  - 判断是否满足成交条件
  - 满足则进入结算，否则进入下一轮
第2-5轮：
  - 剩余玩家继续出价
  - 重复判断流程
### 7.3 结算阶段
1. 确定拍卖成功者
2. 扣除成功者账户金额
3. 物品转移至成功者仓库
4. 计算其他玩家围观奖励（如有）
5. 显示箱子完整信息和价值（缓慢揭示/可跳过）
6. 显示本次成交价与成功者本次收益（盈亏）
7. 玩家选择物品处理方式
---
## 8. 结算展示规则（重点）
- 所有人可见完整物品列表与箱子总价值  
- 展示方式为“缓慢揭示”：物品按顺序依次渲染  
- 物品以品质颜色框标识（白/绿/蓝/橙/红）  
- 若玩家点击“跳过”，则立即显示全部物品与总价值  
- 结算界面需展示：本次成交价 + 拍卖成功者本次收益（盈亏）
