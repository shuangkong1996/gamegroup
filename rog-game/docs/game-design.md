# 《纹铸》游戏设计文档

工作名，可以改。这是一款横屏像素风、单机、纯前端的二维肉鸽幸存者。结构参考了[灵魂锻炉](https://soulforge.glasden.top/)里已经验证过的循环：波次战斗、补给站、随机被动、锻体、羁绊和波次账本。角色、故事、数值和具体条目都按这个项目重新设计。

## 1. 一句话

在一局不断加码的波次里打钱。角色自带一个本命技能；局内再抽两份主动技能和若干被动天赋。天赋负责把这些技能改成意想不到的样子，装备、技能和天赋再用同一套标签连到一起。金币照旧锻进身体。

## 2. 设计支柱

1. **钱是玩法。** 每种收入都有名字，出现在波次账本里。天赋可以新开一条收入，也可以让旧渠道变贵、变险、变延迟。
2. **按钮少，改写多。** 每个角色只有一个本命技能。随机主动技能最多再占两个槽。随机天赋全是被动，其中一部分专门强化、扭曲或组合这些技能。
3. **组合分成宽、窄两层。** 宽层是规则：标签、钩子、连段、施加与消耗、同词缀并持。新技能和新装备写上标签就会自动接上。窄层是一张短的具名表，只收录值得被说出来的那几对。
4. **锻体仍然是看得见的身体成长。** 它加属性和脉络拐点，不和技能槽抢位置。
5. **攻击要有冲击，结算要有获得感。** 命中闪白、伤害数字和金币弹跳先于新内容。每波结束先展示账本，再做选择。
6. **状态效果是一条管道。** 灼烧、护盾、标记、连段都走同一套事件和伤害包。

## 3. 玩家会记住的瞬间

- 抽到一张写着「强化你的本命」的天赋之后，原来的冲刺终点多了一次爆炸。
- 两个主动技能在 1.2 秒内接上，第二下吃到连段，并且触发了一条早就写在装备上的钩子。
- 暂停里的连携页从「还差一个标记技能」变成亮起的名字。
- 锻体从凡躯推到铜躯，人物外形和伤害数字一起变。
- 账本里某一栏突然变长，因为这局的天赋把钱从「击杀」改成了「利息」或「期货」。

## 4. 世界语气

一片被叫做「纹市」的圆形斗场。观众不出现，只有地面的环纹、补给站的帘子和天上偶尔裂开的光。角色是来纹市打短工的斗士。没有阵营剧情，没有多结局长文本。营地只负责选人、看图鉴、花灵魂钱币做少量永久加成。

失败叫「收工」。通关叫「结清」。元货币叫灵魂钱币，只在局外花。

## 5. 循环

```
营地 → 选模式 / 选人 → 波次战斗
        → 本波账本
        → 若本波有天赋或技能，先三选一
        → 补给站（装备、锻体、药水，偶尔有技能残页和黑市）
        → 下一波
        → 倒下或结清 → 灵魂结算 → 营地
```

先选天赋或技能，再进商店。玩家带着新的标签去买装备，连携才接得上。

一场标准局大约 25–35 分钟。演练大约 8 分钟。困难局大约 40–50 分钟。

战斗中不暂停购物。药水是战斗里唯一的消耗品。

## 6. 模式与波次

| 模式 | 波数 | 首领 | 解锁 |
| --- | --- | --- | --- |
| 演练 | 5 | 第 5 波 | 默认开放，可跳过；以后仍可从营地补打 |
| 标准 | 20 | 第 10、20 波 | 默认开放 |
| 困难 | 30 | 第 5、10、15、20、25、30 波 | 标准通关后开放，并打开炉温 |

前 10 波困难与标准共用敌人表。第 11 波起提高生命、伤害和精英率，并降低史诗以上装备、棱彩天赋、完美锻体碎片的出现权重。

标准模式的选择点：

| 波次结束后 | 出现 |
| --- | --- |
| 2、6、11、16 | 天赋三选一 |
| 4、9、14 | 技能三选一 |

困难在第 8、13、19、25 波后给天赋，在第 5、11、17、23 波后给技能。演练只在第 2 波后给一次教学天赋，第 3 波后给一次教学技能。

每一波有时长。清完场上敌人可以提前进入账本。时间耗尽则剩余敌人狂暴：移速和伤害提高，不再掉落普通金币。首领波没有普通倒计时，打死首领即结束。

精英大约每 3 波插入 1–2 个。赏金怪是单独的金币史莱姆，不进常规编队，由特定天赋或随机事件生成。

## 7. 操作

横屏。键鼠为主，触屏保留一套摇杆。

| 操作 | 键鼠 | 触屏 |
| --- | --- | --- |
| 移动 | WASD 或点地 | 左下摇杆 |
| 普攻 | 自动，朝最近或锁定目标 | 同左 |
| 本命技能 | Q 或鼠标右键 | 本命键 |
| 习得技能 | E、R | 两个技能键 |
| 药水 | 1 / 2 / 3 | 右下三格 |
| 暂停 | Esc | 暂停键 |

空着的技能槽不显示按键。普攻默认自动瞄准。玩家可以点选一个目标锁定，锁定期间普攻和指向技能打它。锁定目标死亡后回到最近敌人。

商店里：左键购买，拖动交换装备栏和背包，R 刷新，C 打开合成表和连携表，1–3 选择锻体碎片和三选一。

## 8. 属性

属性分成三组，界面和锻体脉络都沿用这三组颜色。

**杀伤**

| 属性 | 缩写 | 规则 |
| --- | --- | --- |
| 攻击力 | AD | 普攻和大多数物理技能的基底 |
| 法术强度 | AP | 技能、灼烧和魔法弹射的基底 |
| 攻击速度 | AS | 百分比。普攻间隔 = 基础间隔 / (1 + AS) |
| 暴击率 | Crit | 上限 100%。暴击伤害默认 150%，可被装备提高 |
| 技能急速 | AH | 冷却 = 基础冷却 × 100 / (100 + AH) |
| 全能吸血 | OV | 造成伤害的一定比例转生命，持续伤害按 1/3 结算 |

**坚韧**

| 属性 | 缩写 | 规则 |
| --- | --- | --- |
| 生命 | HP | 最大生命 |
| 护甲 | Armor | 物理减伤 = Armor / (Armor + 100) |
| 魔抗 | MR | 魔法减伤，公式与护甲相同 |
| 伤害减免 | DR | 在护甲魔抗之后，百分比再减一次，上限 40% |
| 闪避 | Dodge | 上限 45%。只对可闪避的弹道和近战普攻生效，对地面预警圈无效 |

**机缘**

| 属性 | 缩写 | 规则 |
| --- | --- | --- |
| 移速 | MS | 像素/秒，并影响部分脉络的电能累计 |
| 幸运 | Luck | 掉落、商店高品质、暴击掉金的权重加成 |
| 拾取范围 | Pickup | 金币和球被吸过来的半径 |
| 金币获取 | Gold% | 所有正向金币渠道的乘数，默认 0 |

真实伤害不吃护甲、魔抗和伤害减免，仍然吃护盾。

## 9. 战斗管道

所有伤害、治疗和大多数构筑效果都进同一条管道。内容只声明「监听哪个事件、发出什么包」，不直接改生命值。

### 9.1 伤害包

```
Damage {
  amount        数值
  type          physical | magic | true
  tags          attack | skill | dot | thorns | proc | combo | environment
  sourceId      天赋、装备、羁绊、技能或连携的 id
  owner         玩家或敌人
  target
  crit          是否已暴击
  procRatio     连锁衰减，默认 1
  depth         由其他效果触发时 +1
  skillId       若来自技能，记下是哪一个
}
```

结算顺序：

1. 累加伤害加成（天赋、炉温、身体境界的百分比伤害）。连段中的第二下和第三下在这里吃连段系数。
2. 若带 `attack` 且攻击者暴击判定成功，金额乘暴击伤害，并广播 `onCrit`。
3. 物理扣护甲，魔法扣魔抗，真实跳过。
4. 再乘伤害减免。
5. 护盾吸收，广播 `onShieldAbsorb`。
6. 扣生命。生命到 0 则广播 `onKill`，并中断这只单位身上尚未结算的反击。
7. 广播 `onDamageDealt` 与 `onDamageTaken`。
8. 全能吸血按最终扣血量治疗；`dot` 标签的吸血系数是 1/3。

`depth` 上限为 4。超过上限的包直接丢弃。同一个 `sourceId` 不能出现在自己的触发链上，避免荆棘打荆棘、闪电打闪电。由效果打出的包继承 `procRatio`，默认再乘 0.7。

### 9.2 事件

| 事件 | 时机 |
| --- | --- |
| onHit | 普攻命中并完成伤害之后 |
| onSkill | 技能成功施放。事件带 skillId、槽位（本命或习得）、技能标签 |
| onSkillHit | 技能的某一段命中 |
| onCombo | 连段窗口内施放了另一个技能 |
| onMarkConsume | 一个技能消耗了目标身上的标记 |
| onBurnConsume | 一个技能按层数结算并移除灼烧 |
| onCrit | 一次攻击暴击 |
| onKill | 击杀 |
| onDodge | 闪避成功 |
| onDamageTaken | 受到已结算伤害 |
| onTick | 每 0.5 秒 |
| onWaveEnd | 本波账本生成之前 |
| onShopReroll | 刷新商店 |
| onPurchase | 买下装备、药水、锻体或技能残页 |

羁绊拐点、天赋、装备词条和连携都是这些事件上的监听器。监听器可以改下一步要发出的包，也可以挂状态。

### 9.3 状态

```
Status {
  id            burn | slow | stun | shield | haste | mark | energized
  stacks        当前层数
  maxStacks
  duration      秒，刷新时按该效果自己的规则决定覆盖或叠加
  tick          跳伤间隔，没有则为 0
  sourceId
  payload       每层伤害、减速比例等
}
```

首发状态：

| 状态 | 规则 |
| --- | --- |
| 灼烧 | 最多 5 层。再次施加刷新持续时间，不刷新已经在跳的那一拍。每秒造成 `层数 × (基础 + 系数 × AP)` 魔法伤害，标签 `dot`。带「消耗灼烧」的技能按当前层数打一笔爆发，然后移除灼烧 |
| 缓速 | 不叠加。新的缓速取减速更高的一个。移速按百分比下降 |
| 眩晕 | 不叠加。期间不能移动、普攻、放技能。敌人的预警技能会被打断，已经画在地上的圈仍然结算 |
| 护盾 | 可叠加数值，各自记剩余时间。吸收时先扣剩余时间短的 |
| 急速 | 攻速或技能急速的限时加成，同 id 刷新持续时间 |
| 标记 | 最多 3 层。带「消耗标记」的技能结算额外效果后移除全部标记 |

治疗是另一种包：`Heal { amount, sourceId, tags }`。它先受到治疗加成，再被禁疗类效果改成 0。首发没有禁疗，管道先留这个位置。

### 9.4 连段

连段是技能和技能之间的底噪，不依赖某一对专属配方。

从一次技能施放开始，1.2 秒内施放**另一个**技能，称为连段。窗口内最多记到第三下。

| 第几下 | 效果 |
| --- | --- |
| 第一下 | 打开窗口，广播 `onSkill` |
| 第二下 | 伤害 +15%，包上增加 `combo`，广播 `onCombo` |
| 第三下 | 伤害 +30%，并消耗窗口。本命和两个习得都按过时才会出现 |

同一个技能在窗口内再按一次，只算冷却，不推进连段。这样两个技能就能形成来回连段，第三个技能把窗口打满。

具名连携可以监听 `onCombo`，在这 15% 之外再加自己的效果。

### 9.5 表现和逻辑分开

逻辑层只产生事件：`hit`、`damage`、`gold`、`statusApplied`、`dash`、`impact`、`combo`。表现层听这些事件去播闪白、数字、震屏、音高。震屏有全局冷却 0.12 秒，本命技能的改写爆发可以突破一次。数字同帧合并，避免一层灼烧刷十个字。

## 10. 角色

首发三名。每人有普攻、一句本命被动、一个本命技能。本命技能不能替换，不能丢进背包。随机天赋可以改写它。

本命被动是角色的手感，篇幅保持一句。随机天赋才是海克斯式的被动库。

### 刃卫

近战。基础攻击间隔 0.85 秒，短刀弧，可打到弧内全部敌人。

- 本命被动「回刃」：每第 4 次普攻向前冲 48 像素，这一下攻击力加成 40%。
- 本命技能「短折」：向指针方向短冲，路径上的敌人受到 20 + 70% AD 物理伤害，并缓速 30% 共 1 秒。基础冷却 7 秒。标签：位移、缓速。

### 咒炮

远程。基础攻击间隔 1.05 秒，单发魔法弹。

- 本命被动「余温」：普攻对目标施加 2 秒灼烧，每层每秒 4 + 10% AP。
- 本命技能「热核」：延迟 0.4 秒的小范围爆炸，30 + 60% AP 魔法伤害，中心额外 1 层灼烧。基础冷却 6 秒。标签：范围、施加灼烧。

### 行客

中距离匕首，攻速快，生存靠闪避和走位。

- 本命被动「步幅」：连续移动攒电能，100 点时下一次普攻释放闪电链，弹射 3 次，每跳 15 + 40% AD + 20% AP。
- 本命技能「错步」：向后跳一小段，0.6 秒内闪避 +40%。基础冷却 8 秒。标签：位移、闪避。

## 11. 习得技能

习得技能是局内抽到的主动技能，和本命分开。

### 11.1 槽位与获取

两个槽，对应 E 和 R。获取方式有三种：

1. **波次三选一。** 展示 3 张。已拥有的技能显示为升阶，而不是一张没用的重复卡。
2. **商店里的技能残页。** 残页写明具体技能和价格，买下即学会或升阶。标价落在稀有装备那一档。每站最多 1 张，不是每站都有。
3. **替换。** 两个槽都满、抽到新技能时，玩家选择替换哪一个，或跳过。被替换的技能消失，升阶进度一并消失。本命技能不在替换范围内。

可以放弃三选一，放弃不补偿。每局有 1 次重抽，天赋选择和技能选择共用这一次。

### 11.2 升阶

升阶是技能自己的成长，用来让「再见到同一张卡」变成收获，而不是一张废卡。升阶不新增标签，也不单独构成一条具名连携。宽层照旧读它的原标签。

| 阶 | 变化 |
| --- | --- |
| 1 | 基础效果 |
| 2 | 伤害和附带数值 +30%，冷却缩短 10% |
| 3 | 在 2 阶之上加一句该技能自己的变化，写在技能表的「3 阶额外」里 |

3 阶的那一句只强化这一份技能，例如环斩多一段回复、光束的最后一段改成真实伤害。若希望两个东西凑在一起才发生，写进窄层，不写进升阶。

### 11.3 标签

每份技能 1 到 2 个标签。标签是组合的公共语言，装备、天赋、羁绊都读它。

| 标签 | 含义 |
| --- | --- |
| 位移 | 会移动施法者 |
| 范围 | 打一片 |
| 弹射 | 会在目标间跳跃 |
| 施加灼烧 / 消耗灼烧 | 挂灼烧，或按层数爆掉灼烧 |
| 施加标记 / 消耗标记 | 挂标记，或吃掉标记打出额外效果 |
| 缓速 | 附带缓速 |
| 护盾 | 给自己护盾 |
| 闪避 | 附带闪避窗口 |

「施加」和「消耗」成对出现。任意一个会挂标记的技能，配任意一个会吃标记的技能，都有基础联动。具名连携再在这之上加惊喜。

### 11.4 首发技能池

| 技能 | 标签 | 1 阶 | 3 阶额外 |
| --- | --- | --- | --- |
| 环斩 | 范围 | 0.35 秒前摇，周围 40 + 110% AD 物理伤害。基础冷却 14 秒 | 命中 3 名以上时回复 6% 最大生命 |
| 光束 | 范围 | 引导 1.0 秒，每 0.2 秒 12 + 20% AP。基础冷却 16 秒 | 引导结束时的最后一段改为真实伤害 |
| 点名 | 施加标记、消耗标记 | 标记 3 秒内打过自己的敌人，再次按下或时间结束时每人 20 + 40% AD + 30% AP，并消耗标记。基础冷却 15 秒 | 结算时吸回这段时间所受伤害的 15% |
| 火种 | 施加灼烧 | 对目标及邻近抛出 3 枚火星，各 1 层灼烧。基础冷却 7 秒 | 火星弹射到第二个目标 |
| 爆燃 | 消耗灼烧、范围 | 小范围爆炸。目标每有 1 层灼烧，追加 10 + 15% AP，然后移除灼烧。基础冷却 8 秒 | 若一次消耗了 4 层以上，回复 5% 最大生命 |
| 钉刺 | 施加标记 | 单体 25 + 60% AD，施加 1 层标记。基础冷却 5 秒 | 对已有标记的目标改为消耗 1 层并重置自身冷却 1 秒 |
| 收账 | 消耗标记 | 对一名敌人造成 15 + 40% AD。每消耗 1 层标记，额外掉 1 金币，记入击杀渠道。基础冷却 6 秒 | 若消耗了 3 层，再掉 4 金 |
| 链闪 | 弹射 | 闪电链 4 跳，每跳 18 + 35% AD + 20% AP。基础冷却 9 秒 | 最后一跳施加缓速 |
| 立盾 | 护盾 | 获得 18% 最大生命的护盾，持续 4 秒。基础冷却 12 秒 | 护盾存在时，下一次本命技能伤害 +20% |

咒炮已经有本命灼烧时，火种仍然可以拿，两者叠加层数。行客的本命被动和链闪不是同一个 `sourceId`，可以同时存在。

## 12. 经济与账本

局内只有金币。灵魂钱币不进本局商店。每笔金币都带渠道，波次账本按渠道汇总，每种渠道一种颜色。零收入的渠道不占行。

| 渠道 | 默认来源 |
| --- | --- |
| 击杀 | 普通敌人 1 金 |
| 精英 | 精英 4 金 |
| 首领 | 首领 15 金，外加下一站一件史诗及以下装备的六折券，离开商店后消失 |
| 波次 | 第 n 波结束奖励 `4 + n` 金 |
| 利息 | 默认关闭。效果写入利率和上限后，波次结束获得 `min(上限, 持有金币 × 利率)` |
| 赏金 | 金币史莱姆，打死掉 6–10 金 |
| 期货投入 | 负数。购买期货天赋时立刻支付 |
| 期货回款 | 若干波之后返还投入的固定倍数 |
| 退课 | 黑市卖掉习得技能时的收入 |
| 暴击掉金 | 暴击时的概率掉落 |
| 拾遗 | 场景里捡起的金币；若来源明确，归进原来的渠道 |

金币获取百分比最后乘到所有正收入上。期货投入是支出，不受这个加成。

支出也进账本：装备、刷新、锻体、药水、期货、黑市的预锻。合成购买时，成品标价减去材料已花的金币（含升星），差额才是实付。

本波结束先打开全屏账本，数字从旧值滚到新值，确认后再进入天赋或技能选择，然后才是补给站。暂停里可以看本局累计，渠道顺序与波次账本相同。

## 13. 组合：宽层与窄层

组合只有两层。宽层靠规则自动发生，窄层靠一张具名表。装备与装备、装备与技能、技能与技能、天赋与技能、锻体与技能都走这两层，不另起一套系统。

玩家在暂停和商店里打开同一张表。宽层显示「你现在接上了哪些规则」。窄层显示已经亮起的名字，以及只差一个条件的名字。

### 13.1 宽层

宽层不点名具体的两件东西。内容只要带上标签、词缀或钩子，就和已有的东西接上。

| 规则 | 什么时候发生 | 默认结果 |
| --- | --- | --- |
| 羁绊 | 装备、天赋、技能（含本命）的羁绊标签叠层 | 到达 2 / 4 / 6 层时点亮第 15 节的效果 |
| 钩子 | 装备或天赋写着「当你施放带某标签的技能」 | 任意带该标签的本命或习得技能都会触发，包括以后新加的技能 |
| 连段 | 1.2 秒内施放另一个技能 | 第二下伤害 +15%，第三下 +30%，并广播 `onCombo`。规则见第 9.4 节 |
| 施加与消耗 | 一份技能会挂灼烧或标记，另一份会吃掉它 | 消耗技能按自己的描述，用目标身上的层数结算。火种配爆燃、钉刺配收账，不需要再写一条连携 |
| 词缀并持 | 装备栏里有两件相同词缀 | 触发该词缀的通用效果。背包里的材料不算 |

词缀并持是装备和装备的宽层。每个词缀一条，不逐对写装备名：

| 词缀 | 两件并持时 |
| --- | --- |
| 刃 | 普攻伤害 +12% |
| 咒 | 灼烧跳伤 +10% |
| 风 | 位移技能冷却缩短 8% |
| 市 | 波次奖励 +3 |

钩子的写法固定成「标签 + 时机 + 一件事」。例如「位移技能的路径留下 2 秒火焰」。禁止写成「只有短折可以触发」。若只有某一个技能配某一件装备才成立，那是窄层。

施加与消耗的默认结算：

- 消耗灼烧：按该技能自己的每层伤害追加，然后移除灼烧。没有层数时，技能仍造成它的基础伤害。
- 消耗标记：按该技能自己的每层效果结算，然后移除全部标记。
- 同一次施放只消耗一次。连段里的下一击若也是消耗技能，吃到的是消耗之后剩余的层数。

### 13.2 窄层

窄层是具名连携。每一条都有名字，条件写死到具体的技能、天赋、装备、角色或脉络拐点。凑齐时多出一个宽层不会自动给的效果，HUD 闪一次这个名字。

首发控制在 12 条以内。一条窄层要同时满足：玩家愿意把它讲给别人听；它跨了两类东西；它不是把宽层的数字再加 5%。

| 名字 | 配对 | 条件 | 效果 |
| --- | --- | --- | --- |
| 回环 | 技能 × 技能 | 刃卫的短折，且习得环斩 | 短折若在连段中施放，终点打出一次不耗冷却的半伤环斩 |
| 燃尽 | 技能 × 技能 | 同时拥有火种和爆燃 | 爆燃消耗灼烧后留下 1 层，而不是清零 |
| 点钞 | 技能 × 技能 | 拥有收账，且拥有任意会施加标记的技能 | 收账掉落的金币改记入「赏金」，并再 +1 |
| 炉舌 | 技能 × 装备 | 装备传说武器「炉舌」，且拥有任意消耗灼烧的技能 | 消耗灼烧时，被消耗的层数每层向邻近溅射一半伤害 |
| 折靴 | 技能 × 装备 | 装备传说鞋子「折靴」，且本命是位移 | 本命位移获得第二段，第二段伤害为第一段的 50%，不再次触发路径钩子 |
| 残页夹 | 装备 × 装备 | 同时装备「炉舌」和「折靴」 | 位移的第二段终点施加 2 层灼烧。词缀并持仍然单独生效 |
| 过热 | 天赋 × 技能 | 拥有天赋「炉心」，且拥有任意消耗灼烧的技能 | 炉心向外传播时改为传播 2 层 |
| 白热 | 锻体 × 技能 | 咒脉络达到 6，且拥有光束 | 光束最后一段改为消耗目标全部灼烧，按爆燃一半的伤害结算 |
| 残影 | 角色 × 技能 | 行客，且拥有任意消耗标记的技能 | 错步的闪避窗口里若闪避成功，给攻击者 1 层标记 |

窄层条件可以用「任意带某标签」，但效果必须是宽层给不了的行为变化，例如留下 1 层、多出第二段、改记账渠道。单纯的伤害百分比留给钩子和羁绊。

新内容先写标签和钩子。只有玩过一次就想复述的组合，才加进这张表。

## 14. 天赋

天赋是随机被动，对应海克斯乱斗里的强化。它们不占技能槽，不能在战斗中按出。

一局大约 4 次三选一，节奏见第 6 节。每次 3 张，可以放弃。重抽与技能选择共用每局 1 次。

### 14.1 品质

| 品质 | 颜色 | 出现 | 强度 |
| --- | --- | --- | --- |
| 白银 | 冷银 | 前两次选择的主要品质 | 一条小规则、少量属性，或对本命的轻改写 |
| 黄金 | 金 | 中期开始混入 | 改打法、改收入，或明显改写某个技能 |
| 棱彩 | 虹 | 困难更晚、更少；标准最多 1 张 | 一条局内身份，通常带代价或极强的技能改写 |

品质权重受幸运影响：每点幸运让黄金权重 +2%，棱彩权重 +0.5%。

### 14.2 四类天赋

抽取时按当前构筑加权，让「强化我已经有的技能」比纯随机更常出现。

| 类别 | 抽到时玩家看到什么 | 权重 |
| --- | --- | --- |
| 通用 | 收入、属性、普攻监听 | 始终有 |
| 本命改写 | 卡面写着角色的本命技能名 | 该角色恒定权重，黄金之后升高 |
| 标签钩子 | 「你的位移技能……」 | 已经拥有该标签时权重加倍；没有该标签时仍可能出现，卡面注明尚未接上 |
| 连携种子 | 卡面写出还缺的技能、装备或脉络 | 已完成一半时权重明显提高 |

一张天赋只做一件事，并在卡面上属于下面之一：

- **改写技能**：改本命或某一类标签的行为。
- **新机制**：给普攻或受击加监听器。
- **属性**：直接加 AD、AP、急速。这类要少，避免天赋变成第二套锻体。
- **收入**：新开或改造一个账本渠道。

黄金和棱彩可以带一句代价，规则见第 14.4 节。白银通常不带。

一张天赋最多挂 1 个羁绊标签。监听器的 `sourceId` 使用 `talent:<id>`，并遵守深度和衰减。

### 14.4 代价

代价是天赋上的发散，用来让强效果带着一个能写进账本或手感里的负担。它不是负面天赋池，一张带代价的卡仍然是奖励。

- 只有黄金和棱彩带代价，而且卡面把代价写成单独一行。
- 代价和收益是同一张卡，不能只拿收益。
- 代价优先改行为或经济：刷新变贵、自己掉血、技能急速下降、本命冷却变长。少用「全属性 -10%」这种看不出打法变化的惩罚。
- 持续掉血进伤害管道，标签为 `environment`，不触发荆棘，避免代价把自己打出无限反击。
- 经济代价记入账本。金身让刷新费用涨得更快，玩家能在支出里看见。

## 15. 羁绊

羁绊不是单独购买的东西。计数等于「已装备的带标装备 + 已选的带标天赋 + 已学会的带标技能」。背包里的材料不计。同一件装备只计一次，升星不加层。本命技能的标签也计数。

标准模式最高计到 4 层。困难模式最高 6 层，并且商店可以出现对应纹章：一件没有属性、只提供 1 层指定羁绊的装备。

首发 6 组。

| 羁绊 | 2 层 | 4 层 | 6 层 |
| --- | --- | --- | --- |
| 灼痕 | 灼烧伤害 +25% | 你施加灼烧时，若目标已有 3 层以上，立刻结算 1 秒跳伤 | 灼烧每跳有 25% 几率永久提高该目标所受灼烧 1%，上限 30% |
| 连锁 | 弹射次数 +1 | 弹射可以弹回主目标，但回弹 `procRatio` ×0.5 | 每 5 秒自动放出一次满额闪电链，不消耗电能 |
| 金库 | 金币获取 +15% | 利息 +10%，上限 +40；刷新费用减半 | 每波结束，若持有金币高于 80，下一波伤害 +15% |
| 坚壁 | 护甲与魔抗 +10 | 受到伤害获得 6% 最大生命护盾，4 秒冷却 | 护盾存在时，造成伤害的 10% 转为真实伤害 |
| 迅捷 | 攻速 +12% | 闪避后获得 25% 移速，持续 1.5 秒 | 攻速超过 80% 的部分，每 10% 转化为 4 AD 与 4 AP |
| 药瓶 | 喝药间隔从 6 秒改为 4 秒 | 药水格被喝空后，下一站商店的药水标价降低 30% | 同时携带 3 种不同药水时，三条药水效果各 +20% |

羁绊在暂停和补给站里显示当前层数，以及下一档还差几件，并注明这几件可以是装备、天赋或技能。刚跨过一档时，战斗 HUD 上闪一次羁绊名。

## 16. 锻体

锻体是本局最长的一条成长，也是商店里的主菜。玩家花金币锻造碎片，三选一，付款后必须选一张，不能退。

锻体不加技能槽，也不直接替换本命。它通过属性和脉络拐点去喂技能：咒脉络让技能会烧人，风脉络让闪避推进本命冷却，市脉络让持有的金币变成攻击。

### 16.1 碎片

每张碎片属于一条脉络，并有品质。

| 品质 | 售价感觉 | 每张提供 |
| --- | --- | --- |
| 普通 | 见曲线 | 该脉络的基础每枚属性 |
| 精良 | 普通的 1.6 倍 | 基础属性 ×1.8，并带一句小词条 |
| 完美 | 普通的 2.4 倍 | 基础属性 ×2.6，并带一句较强词条 |

价格曲线按本局已锻造次数 `k`（从 0 起）：

`基础价 = 8 + 3k`

第 1 次 8 金，第 5 次 20 金，第 10 次 35 金。品质乘数打在基础价上。刷新商店不刷新已经付过款、还没选的三选一。

脉络每枚基础属性：

| 脉络 | 每枚普通碎片 |
| --- | --- |
| 刃 | +2 AD |
| 咒 | +3 AP，+1 技能急速 |
| 风 | +1.5% 移速，+1% 攻速 |
| 市 | +4% 金币获取，+1 幸运 |

精良和完美的额外词条从该脉络的小表里抽，例如刃的「普攻范围 +4 像素」、咒的「灼烧持续时间 +0.5 秒」、风的「电能获取 +8%」、市的「利息上限 +5」。词条可以重复，重复则叠加。

### 16.2 脉络拐点

某一脉络的碎片数量达到 3、6、10 时，获得该拐点。只取最高一档，低档效果保留。困难模式可以继续堆，但 10 之后不再有新拐点，只加每枚属性。

**刃**

- 3 连斩：每第 3 次普攻对主目标额外造成 15 + 40% AD 物理伤害。
- 6 溅射：普攻对主目标附近再造成 40% 伤害。
- 10 断金：普攻对生命高于 60% 的目标伤害 +20%。

**咒**

- 3 余烬：技能命中施加 1 层灼烧。
- 6 回热：灼烧每跳有 20% 几率返还 1 点技能急速，持续到本波结束，最多 20。
- 10 白热：你的灼烧伤害改为 50% 魔法、50% 真实。真实的那一半仍然带 `dot`。

**风**

- 3 拾阶：拾取范围 +40%。
- 6 踏电：电能上限仍是 100，获取速度 +30%。
- 10 风行：闪避 +12%。闪避后本命技能冷却推进 1 秒。

**市**

- 3 招财：击杀有 8% 几率额外掉 1 金。
- 6 利市：利息 +8%，上限 +20。若还没有利息，则开启这条渠道。
- 10 金身：每持有 15 金，+1 AD 与 +1 AP，最多各 40。与棱彩天赋「金身」同时存在时，取更高的「每多少金 +1」，加成上限相加，但总上限不超过 70。

### 16.3 身体境界

全脉络碎片总数决定身体，和某一条脉络的拐点分开计算。

| 碎片总数 | 境界 | 效果 | 外形 |
| --- | --- | --- | --- |
| 0 | 凡躯 | 无 | 基础精灵 |
| 5 | 铜躯 | 伤害 +4%，伤害减免 +2% | 肩和刃口换成铜色 |
| 12 | 银躯 | 伤害 +8%，伤害减免 +4%，生命 +5% | 胸口一道银纹 |
| 20 | 金躯 | 伤害 +14%，伤害减免 +6%，生命 +10% | 金纹包住前臂 |
| 30 | 精金之躯 | 伤害 +22%，伤害减免 +8%，生命 +15%，攻速 +15% | 轮廓多一像素亮边 |

跨境界时补给站播放一次短锻打，人物在下一波出场有 0.6 秒的亮相。战斗 HUD 永远显示当前境界名。

锻体面板用一张简图：四条脉络从躯干伸出，已锻的碎片点亮。悬停看这张碎片的属性、词条和它把哪一档拐点推近了。

## 17. 装备与合成

装备提供属性、一个词条，通常还有 1 个羁绊标签。装备栏 6 格。背包 2 格，只放材料，不生效。两格之间可以拖动互换。

升星：相同 id 的装备再买到或合成到时升 1 星，最多 3 星。每星让该装备的数值词条 +40%。羁绊标签不因升星增加层数。

### 17.1 词条类型

- 属性词条：AD、AP、攻速、急速、生命、护甲、魔抗、吸血、暴击。
- 钩子词条：监听技能标签或连段。例如「位移技能的路径留下 2 秒火焰，每秒 8 + 10% AP」。一件装备最多一个钩子。
- 并持词缀：刃、咒、风、市。两件相同词缀同时装备时触发第 13.1 节的宽层并持。词缀可以和羁绊标签不同。
- 羁绊标签：0 或 1 个。纹章没有属性，只有标签。

钩子是装备和技能联动的主要做法。具名连携只留给特别值得记住的几对。

### 17.2 首发装备方向

| 品质 | 件数 | 作用 |
| --- | --- | --- |
| 普通 | 8 | 纯属性或很弱的钩子，合成材料 |
| 稀有 | 6 | 一个清晰钩子，例如「消耗标记时回复 2% 生命」「连段第二下 +10% 伤害」 |
| 史诗 | 4 | 改变某个标签的节奏，例如「位移技能命中后，普攻间隔立刻重置一次」 |
| 传说 | 2 | 「折靴」强化位移，并进入窄层；「炉舌」强化灼烧消耗，并进入窄层 |

每件传说至少要吃到两种普通或稀有材料，让玩家在中期就知道自己在追哪条配方。

### 17.3 合成

合成表在商店里用 C 打开，和连携表放在一起。集齐配方的全部材料后，成品有机会出现在商店的合成格，而不是自动合成。这样玩家仍要做一次购买决定。

合成格标价低于直购。材料已经花掉的金币，包括升星，从标价里全额抵扣。抵扣之后若小于 0，则免费，不退还差额。

配方首发 8 条，每条 2 或 3 个材料。至少 3 条配方跨羁绊，避免最优解永远是从第一波就只买同一个标签。

合成是装备与装备的经济组合，走商店。并持是装备与装备的宽层效果。两件装备可以同时走这两条路：合成出成品之后，成品若仍带词缀，还能和另一件并持。点名两件传说的效果才写入窄层，例如「炉舌」配「折靴」。

## 18. 药水

药水带默认 3 格，可被天赋扩到 4。同一格喝下后进入 6 秒饮用间隔，间隔内不能喝同一格，其它格可以。战斗中喝，商店中只买和丢。

| 药水 | 价格 | 效果 |
| --- | --- | --- |
| 生命药水 | 14 | 立即回复 40% 最大生命 |
| 狂暴药水 | 16 | 8 秒内攻速 +40%，技能急速 +20 |
| 巨像药水 | 16 | 获得 25% 最大生命的护盾，持续 6 秒 |
| 点金药水 | 18 | 8 秒内击杀金币翻倍。这个加成记在击杀渠道上，账本能看见 |

商店每站最多同时展示 2 瓶。已经携带的药水可以被买下并替换，被替换的那瓶消失，不退款。

药水可以挂「药瓶」标签，从而参加羁绊。首发四瓶都挂这个标签。

## 19. 黑市

黑市是补给站旁边偶尔多出来的一张摊。它把「这一局的钱」和「这一局的构筑」做成一笔带代价的交换：用生命买一次天赋，用技能换金币，用下一波的危险换掉落，用现钱买下一次锻体的品质。

标准局出现 1 次，放在第 8 波到第 14 波之间的某次补给站。困难局出现 2 次，第二次放在第 18 波之后。演练不出现。黑市不替换装备、锻体和药水，只是旁边多一张摊。

每次展示 3 笔交易，玩家选 1 笔，或离开。不能刷新，不能买两笔。交易结果立刻生效，并在当波账本的支出或收入里出现。

| 交易 | 得到 | 付出 |
| --- | --- | --- |
| 加练 | 立刻进行一次额外的天赋三选一，品质权重与最近一次天赋选择相同 | 失去 15% 当前生命；下一波开始时再失去 15% 最大生命。这两段伤害标签为 `environment`，不触发荆棘 |
| 退课 | 获得 25 到 40 金币，记入渠道「退课」 | 丢掉一个习得技能及其升阶。本命技能不能退 |
| 加钟 | 下一波精英数量翻倍，该波击杀和精英金币翻倍 | 下一波受到的伤害 +15% |
| 预锻 | 下一次锻体三选一必含一张精良或完美 | 立刻支付 15 金 |

没有习得技能时，退课不会出现。已经付过锻体、还没选的那次三选一，不受预锻影响，预锻留给再下一次。

黑市停留在商店里。它不变成地图房间，战斗场地也不撒可破坏的箱子。奖励若从地上捡，账本里的渠道会和击杀混在一起。

## 20. 敌人

敌人没有装备和天赋。它们用行为槽和一种抗性倾向来区分。

| 原型 | 行为 | 玩家要做的事 |
| --- | --- | --- |
| 徒手 | 直线走近，近战 | 风筝或拉扯 |
| 投石 | 保持距离丢慢速石头 | 横移 |
| 疾奔 | 低生命，高速贴脸 | 优先打，或用缓速 |
| 重甲 | 高护甲，慢 | 用魔法、真实或持续伤害 |
| 咒灵 | 高魔抗，死亡时放小范围魔法爆 | 拉开再补刀 |
| 精英前缀 | 在原型上加狂暴、分裂或光环 | 看地面描边颜色 |

预警统一用地面圈，至少提前 0.7 秒。圈的颜色表示伤害类型：物理暖橙，魔法冷紫，真实近白。圈出现时有一声很轻的预兆音，结算时才是打击音。

首领首发 4 个，困难后两个只在对应波次出现。

| 首领 | 波次 | 读招 |
| --- | --- | --- |
| 环纹看守 | 演练第 5 波，标准第 10 波 | 三连近战，然后一个会缩小的安全圈 |
| 账房 | 标准第 20 波 | 周期性把玩家下一笔击杀金币变成 0，持续 5 秒；打破它脚下的账册可以打断 |
| 典狱长 | 困难第 25 波 | 把玩家套进缓慢收缩的环，环外持续受伤 |
| 纹市之心 | 困难第 30 波 | 交替使用前三个首领的一个招式，并把炉温效果再加强一档 |

首领战期间仍显示玩家的灼烧、护盾和冷却。不切换到另一套 UI。

## 21. 炉温

炉温只在困难模式、出发前设置。它是一组可开关的契约，用来把已经通关的人推到更高风险。标准模式不出现。

每条试炼 1–3 档，档位越高炉温越高，敌人越强或资源越少。契约同时给收益和代价。出发后本局不能改。

**试炼方向**（具体系数实现时再标定）：

| 试炼 | 每档大致后果 |
| --- | --- |
| 坚甲 | 敌人护甲、魔抗提高 |
| 利爪 | 敌人伤害提高 |
| 疾行 | 敌人移速提高 |
| 精英横行 | 精英数量提高 |
| 暴君 | 首领生命和伤害提高 |
| 地火 | 场地周期性出现火圈 |
| 枯泉 | 药水回复和护盾效果降低 |
| 吝金 | 击杀和波次金币降低 |
| 凡躯 | 锻体基础价提高 |

**契约：**

- 熔炉狂热：锻体碎片每枚属性提高，但每波开始受到一次可观的真实伤害。
- 贪金之咒：利息和击金提高，商店刷新和装备价格也提高。

通关记录按角色、按炉温分档保存。每个角色首次达到炉温 3、6、10、15、20 时，各领一次灵魂钱币。营地只记录该角色的最高通关炉温。

## 22. 局外

营地是一个可走动的小场景，不是菜单叠菜单。三个交互点就够：传送门、淬炼、图鉴。

灵魂钱币的来源只有结算：到达波次、击杀首领、困难炉温里程碑、首次使用某个角色通关。失败也会按到达波次给少量钱币。

淬炼是永久的、分角色的小加成，例如起始金币 +2、生命 +5%、某个白银天赋的出现权重、某个习得技能在技能池里的权重。它不提供新机制。新机制留在局内的天赋、技能、羁绊和锻体里。价格递增，每个角色一条独立轨道。

图鉴记录见过的天赋、技能、连携、装备、羁绊、锻体词条、敌人和首领。没见过的连携如果已经凑齐一半，会显示条件的另一半剪影。

存档在本地，多槽位。本局中途离开可以「存档退出」，下次从营地继续；放弃本局则丢掉这次远征，保留灵魂钱币以外的已入账奖励。灵魂钱币在结算确认时入账，崩溃不应重复发放。演练不计炉温，不计最高纪录。

## 23. 界面与反馈

像素世界和界面分开。世界是一块固定内部分辨率的画面，界面是叠在上面的清晰文字。数字和快捷键用像素字体，说明用普通黑体。

战斗 HUD：

- 左上：生命、护盾、金币。金币变化时弹出 `+n`，颜色对应该渠道。
- 中上：波次、倒计时、首领血条。
- 右上：天赋图标、已亮羁绊和层数、锻体境界。
- 下方：本命技能、两个习得技能、药水。冷却用扇形扫过。连段窗口用本命键旁的一条短进度表示。
- 连杀在右下短暂出现，连杀本身不给属性，只给反馈。真的连杀收益来自天赋。

补给站分成三栏，顺序固定：装备、锻体、药水。技能残页和黑市出现时贴在装备栏旁边，不另开一页。右侧是构筑：6 个装备格、2 个背包格、药水带、本命与习得技能、天赋、羁绊、分组属性。属性按杀伤、坚韧、机缘折叠。

天赋卡和技能卡如果会改写已有技能，卡面第一行写被改写的技能名，再用一句话写变化。

伤害数字：

- 物理偏暖白，魔法偏紫，真实偏亮白并略大。
- 暴击更大，停留更短。
- 灼烧跳伤更小、更透明，同目标 0.2 秒内合并。
- 连段第二下的数字略微偏高，并带一个小的连接线。

受击：精灵闪一帧近白色，轻微向伤害来源的反方向移 1 像素再回到逻辑位置。逻辑坐标不因为击退表现而改变，除非技能明确带位移。

获得羁绊新档、具名连携、锻体新境界、传说装备时，各用一次不同长度的横幅。横幅不超过 1.2 秒，不阻断操作。

暂停里看两张表：

- 属性来源：每一项可以展开，看到来自基础、装备、天赋、羁绊、锻体、境界、药水、技能升阶的哪一条。
- 连携：已生效的钩子和具名连携，以及只差一个条件的条目。

## 24. 美术

内部分辨率 320×180，整数放大。像素用有限色板，描边用近黑。地面是暗色环纹，敌人用轮廓色相区分原型。

角色大约 16×24。境界变化只换 4 到 6 个像素的金属色。技能用几何形：刃是弧，咒是圆和线，风是折线。本命技能的颜色跟角色走，习得技能的颜色跟自己的主标签走，这样改写之后玩家仍分得清哪一下是谁放的。预警圈用 1 像素虚线加上填充的低透明度。

界面面板是深靛蓝，强调色是暖金，危险是红，魔法是紫，治疗是绿。一种状态只用一种颜色，并且和账本渠道、伤害类型对齐。

动画帧数很少：待机 2 帧，移动 4 帧，攻击 3 帧，受击 1 帧。冲击感来自闪白、位移残影和音效。

## 25. 声音

全部用程序合成的短音。每个音不超过 400 毫秒，本命技能被棱彩天赋改写后的爆发可以到 700 毫秒。

| 事件 | 声音 |
| --- | --- |
| 普攻命中 | 很短的木击或金属点击，音高随攻速略随机 |
| 暴击 | 同一音色升高纯四度 |
| 本命技能 | 角色各一个音色：刃是噪声加点击，咒是正弦滑音，风是两个相隔五度的短音 |
| 习得技能 | 用标签的音色，音量略低于本命，避免盖过角色 |
| 连段第二下 | 在原技能音上加一个高八度的很短泛音 |
| 具名连携亮起 | 两声相隔大三度的音 |
| 灼烧跳伤 | 极轻的噪声，音量随层数增加，但设上限 |
| 金币 | 明亮的五度双音。利息、期货回款和退课用上行三音，彼此差一个音级 |
| 购买与锻造 | 低一点的敲击。跨身体境界时连敲三下，音高上行 |
| 羁绊升档 | 一个清亮的和弦，2 层、4 层、6 层逐次加一个音 |
| 预警 | 几乎听不见的滤波噪声升起；命中时才重 |
| 受伤 | 短促的低频 |
| 倒地与结清 | 倒地是和弦落下，结清是同一和弦反过来升起 |

音乐只铺一层低音持续音，波次后半段略微打开滤波。商店几乎静音，只留环境。所有音效能在设置里关掉，关掉后打击闪白仍然保留。

## 26. 技术结构

纯前端，单页。不设账号、匹配和权威服务器。

- 像素世界用 Phaser 4 的 WebGL，挂在单独容器里。内部分辨率 320×180，`pixelArt` 打开，缩放由游戏自己按整数倍适配窗口。
- 界面用 HTML/CSS 叠在画面上。商店、账本、图鉴、暂停都不画进世界贴图。
- Phaser 自带的音频和物理世界不作为主系统。音效用 Web Audio 现写。碰撞用简单的圆和距离，位移技能用短时间的运动学。
- 内容用数据描述：角色、技能、敌人、波次表、装备、配方、天赋、羁绊、连携、锻体词条、药水、炉温、黑市。监听器指向效果注册表里的 id。
- 技能是数据加一个施放函数。天赋如果改写技能，优先给技能挂修饰器（额外段、额外标签、冷却推进），少去复制一份新技能。
- 战斗核心与表现分离。核心输出伤害包和表现事件。
- 存档放在 `localStorage`，按槽位保存营地进度和未完成的远征。刷新页面时用 `sessionStorage` 记住是否正在一局战斗中。
- 首发可以只有一个 `index.html` 和若干内容脚本。

修饰器示例：

```
modifiers.endpoint = {
  skill: "short-dash",
  onCastEnd(ctx) {
    ctx.damage.area(ctx.position, { amount: 20 + 0.4 * ctx.ad, type: "physical", sourceId: "talent:endpoint" })
  }
}
```

新天赋、新钩子、新连携优先加数据。只有新的事件种类才改管道。

- 天赋约 8 银、11 金、5 棱彩，其中本命改写和标签钩子占一半以上
- 具名连携 8 到 12 条
- 羁绊 6，档位 2/4/6
- 锻体脉络 4，拐点 3/6/10，境界 5 段
- 装备约 20，配方 8，药水 4
- 黑市交易 4 种
- 炉温试炼 9，契约 2

## 28. 完成时玩家应能感到的差别

一场的选择集中在五件可以指认的事：

1. 本命技能被哪张天赋改成了什么样。
2. 两个习得技能在宽层上接上了没有：连段、施加与消耗，或某件装备的钩子。窄层如果亮了，玩家说得出那个名字。
3. 账本里哪一条渠道是这局的主收入。
4. 哪一档羁绊已经亮了，下一档还差装备、天赋还是技能。
5. 身体到了哪一境，四条脉络里哪一条正在接近拐点。

## 29. 已经写进循环的发散

这些是首发规则的一部分，正文里有完整做法：

| 发散 | 它多出来的选择 | 写在 |
| --- | --- | --- |
| 宽层组合 | 新技能只要带标签，就和装备钩子、羁绊、连段、消耗接上 | 第 13.1 节 |
| 窄层具名连携 | 少数跨类型的配对变成能被叫出名字的效果 | 第 13.2 节 |
| 连段 | 两个按钮在 1.2 秒内接上就有差异，不依赖专属配方 | 第 9.4 节 |
| 施加与消耗 | 灼烧和标记自然形成技能配对 | 第 11.3 节、第 13.1 节 |
| 技能升阶 | 重复抽到同一技能是成长，不是废卡 | 第 11.2 节 |
| 技能残页 | 金币可以直接买到一份写明名字的主动技能 | 第 11.1 节 |
| 代价天赋 | 强被动带着一条看得见的负担 | 第 14.4 节 |
| 黑市 | 用生命、技能或下一波的风险换天赋、金币或锻体品质 | 第 19 节 |
| 词缀并持 | 两件同词缀装备有通用效果，不必为每一对起名 | 第 13.1 节 |

## 30. 先留着、以后再考虑的元素

这些能加，但会和现在的支柱抢注意力，首发不放进循环：

- **战斗里的箱子和地形机关。** 土豆兄弟的拾取很强，但纹市的获得感已经放在账本、商店和锻体上。再在地上撒奖励，钱的渠道会变糊。
- **第二套战斗资源。** 怒气、热量如果人人都有，会和电能、标记、灼烧叠成三套层数。电能只留给风脉络和行客。
- **宠物、召唤物、第二名队友。** 组合会从「我的技能」变成「我的单位」，现有管道接不住。
- **把黑市做成随机地图房间。** 现在的黑市是一笔可选交易。做成房间之后，失败感会从构筑变成走错路。
